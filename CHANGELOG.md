# Changelog

Semua perubahan penting pada proyek ini didokumentasikan di berkas ini.

Format mengikuti [Keep a Changelog](https://keepachangelog.com/id/1.1.0/), dan versi menggunakan [Semantic Versioning](https://semver.org/lang/id/).

## [0.1.0] - 2026-10-08

### Added

- Knowledge base lokal untuk catatan, query, dokumen, link, request API, konfigurasi, tiket, dan secret terenkripsi.
- API Node.js dengan SQLite, full-text search, tag, riwayat versi, arsip, trash, relasi antar-item, dan koleksi.
- Import file atau bookmark, ekstraksi teks PDF, DOCX, XLSX, serta OCR gambar Indonesia dan Inggris.
- Backup harian, export data terbuka, CLI `hdb`, dan integrasi tiket Odoo opsional melalui `hesewake-cli`.
- UI React untuk pencarian, quick capture, pengelolaan item, vault, import, pengaturan, serta preview PDF.
- Autentikasi sesi dan enkripsi secret di browser, dengan akses perangkat lain melalui Tailscale.
